Detailed Description

Pseudo-steady convergence monitor for KLAxell RANS runs

Tracks horizontal wind speed and turbulent kinetic energy at a user-supplied cloud of monitor points. A point is considered converged when the peak-to-trough spread of both quantities over a trailing time window falls below tolerance. Once every point has converged the monitor can ask the time integrator to stop, which triggers a final checkpoint and plotfile.

The spread over a window is used in preference to a difference between successive samples because an atmospheric boundary layer under Coriolis and geostrophic forcing approaches its steady state through a damped inertial oscillation. A difference between successive samples vanishes at every turning point of that oscillation and would report convergence long before the oscillation has decayed.

This utility is restricted to the KLAxell turbulence model. The criterion is a drift test on an instantaneous value, which is only meaningful when that value approaches a limit; a large eddy simulation has no such limit.

static

Fit an exponential decay to an envelope history and extrapolate

Performs an ordinary least-squares fit of \(\ln s\) against \(t\), which corresponds to the model \(s(t) = A e^{-rt}\), and solves for the time at which the fitted curve reaches threshold.

The fit is reported as invalid when there are too few samples, when any sample is not positive, when the fitted envelope is not decaying, or when the threshold has already been reached.

Parameters
timesSample times in seconds, in increasing order
spreadsEnvelope spread at each sample time
thresholdValue the extrapolation is solved for
min_samplesFewest samples that will be fitted
Returns
Fit coefficients and the extrapolated time to the threshold
